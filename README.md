<h1 align="center">crystals-kyber-js</h1>

<div align="center">
Post-quantum cryptography implementations written in TypeScript for various JavaScript runtimes.
</div>
<p></p>

This repository is a monorepo that has the following packages:

| package                    | registry                                                                                                                                                                                                                                                                                                                                                                                                                                          | description                                                                                                                                    |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| [mlkem](./packages/mlkem/) | [![JSR](https://jsr.io/badges/@webpqc/mlkem)](https://jsr.io/@webpqc/mlkem) [![npm](https://img.shields.io/npm/v/@webpqc/mlkem?color=%23EE3214)](https://www.npmjs.com/package/@webpqc/mlkem) [![npm](https://img.shields.io/npm/v/mlkem?color=%23EE3214)](https://www.npmjs.com/package/mlkem) [![npm](https://img.shields.io/npm/v/crystals-kyber-js?color=%23EE3214&label=crystals-kyber-js)](https://www.npmjs.com/package/crystals-kyber-js) | An ML-KEM (NIST FIPS 203) implementation. Published as `@webpqc/mlkem` on JSR, and as `@webpqc/mlkem`, `mlkem` and `crystals-kyber-js` on npm. |

See the README of each package for installation and usage.
