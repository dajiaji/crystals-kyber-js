    Function createMlDsa44Verifier

    • createMlDsa44Verifier(): Promise<MlDsaVerifierInterface>

      Creates a pre-initialized ML-DSA-44 (NIST security category 2) verifier with synchronous verification.

      An application which uses only this does not bundle the code for key generation and signing.

      Returns Promise<MlDsaVerifierInterface>

      A promise that resolves to an MlDsaVerifierInterface instance.

      Example

      import { createMlDsa44Verifier } from "@webpqc/mldsa";

      async function verify(pk: Uint8Array, sig: Uint8Array, msg: Uint8Array) {
        const verifier = await createMlDsa44Verifier();
        return verifier.verify(pk, sig, msg);                    // sync
      }
